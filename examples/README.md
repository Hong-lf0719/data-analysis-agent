# 示例（Examples）

> 让面试官 / 使用者**不用跑代码**也能一眼看懂这个 skill 的输出长什么样。

## 1. 示例数据：`sample_sales.csv`

一份脱敏的销售数据（38 行），字段：`日期, 地区, 产品类别, 销售额, 销量, 利润率`。

```bash
python agent.py examples/sample_sales.csv
```

## 2. 示例报告：`示例报告.md`

一份**真实跑通**的完整分析报告（基于就业数据，格式与任何输入一致），包含：

- **数据质量评分**：0–100 综合分（完整性 / 唯一性 / 有效性）
- **数据概况**：形状、字段、摘要
- **数据清洗**：发现问题数 + 清洗动作
- **统计分析**：假设检验表（组别 / 方法 / p 值 / 结论）
- **可视化**：图表（柱状 / 箱线 / 相关热力图等）
- **业务洞察**：LLM 生成的可读结论

## 3. 图表

运行后 `outputs/` 下会生成 PNG 图表（chart_bar.png / chart_box.png / chart_corr.png 等），报告自动内嵌。
